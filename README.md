# TrackMyJob API

![CI](https://github.com/ankithcrgowda/track-my-job/actions/workflows/ci.yml/badge.svg)

A production-grade Job Application Tracker REST API built with Spring Boot 3.5, 
JWT Authentication, PostgreSQL, and Docker.

## Quick Start
\```bash
git clone https://github.com/ankithcrgowda/track-my-job.git
cd TrackMyJob
docker compose up --build
\```

API available at: http://localhost:8080  
Swagger UI: http://localhost:8080/swagger-ui/index.html
